# Appie.run MCP server

Hosted [Model Context Protocol](https://modelcontextprotocol.io) server for [Appie.run](https://appie.run). Full documentation: https://appie.run/docs/mcp

## Basics

- **Name:** Appie.run
- **Server URL:** https://appie.run/mcp (remote, HTTP, JSON-RPC over POST)
- **Auth:** Bearer token. Use a project API key (`esk_...`), generated by a project admin under API in the project sidebar.
- **Categories:** Marketing, Content, Customer support / Chatbots, Link management
- **Pricing:** Free plan with 500 credits, no card needed. That covers about 5 light articles or 500 chatbot replies. Tools that write spend project credits; read tools are free.
- **Docs:** https://appie.run/docs/mcp
- **Website:** https://appie.run

**Write on-brand articles and run AI chatbots from any MCP client**

Appie.run's MCP server lets AI clients write articles in your brand voice, train and query website chatbots, and create trackable short links.

## Overview

Appie.run is an AI marketing stack that learns your brand from your website. Its MCP server lets Cursor, Claude and other MCP clients use the same brand context to get marketing work done.

With one project API key, an agent can:

- **Write articles in your voice.** Start light (~500 words) or deeply researched (~3,000 words) articles using an author profile trained on your writing samples, then check their status until the draft is ready.
- **Manage brand context.** Read and update the project Brain, which holds your website, about text, brand voice, key messages, ideal customer and competitors. Content Writer and chatbots both use it.
- **Build and query chatbots.** Create a chatbot, train it on text, URLs, sitemaps or your Appie articles, check its training status and ask it questions.
- **Create and track short links.** Make links on s.appie.run and read clicks and unique visitors for the last 30 days.

New accounts get 500 free credits, enough to try every tool. Read tools cost nothing. Writes spend the project's credits, and every result shows credits_remaining, so agents always know what's left.

## Tools

| Tool | What it does | Cost |
|---|---|---|
| create_short_link | Creates a short link on s.appie.run, with an optional custom code | 1 credit |
| link_stats | Clicks, uniques and a 30-day series for one link | Free |
| create_article | Starts a light or deeply researched article in a project author's voice (async) | 100 or 500 credits |
| article_status | Status and content of one article | Free |
| list_authors | Lists author profiles and their samples | Free |
| create_author | Creates an author, optionally with a first writing sample | See docs |
| add_author_sample | Adds a text or blog-URL sample to an author (up to 5) | See docs |
| get_brain | Reads the project's brand context | Free |
| update_brain | Updates selected brand context fields | See docs |
| list_chatbots | Lists chatbots and their training status | Free |
| create_chatbot | Creates a chatbot with optional prompt, model and temperature | Free |
| add_chatbot_content | Adds text, URL, sitemap or article knowledge to a chatbot | See docs |
| chatbot_status | Training status and recent sources for one chatbot | Free |
| ask_chatbot | Sends a message to a chatbot and returns its reply | 1 credit |

## Connect

Server URL: `https://appie.run/mcp` (streamable HTTP). Authenticate with a project API key (generated by a project admin under **API** in the project sidebar) sent as a Bearer token. Add this to your MCP client config (see [`examples/mcp-config.json`](examples/mcp-config.json)):

```json
{
  "mcpServers": {
    "appie": {
      "type": "streamable-http",
      "url": "https://appie.run/mcp",
      "headers": { "Authorization": "Bearer YOUR_APPIE_API_KEY" }
    }
  }
}
```

Replace `YOUR_APPIE_API_KEY` with your key. Never commit real keys. See the docs at https://appie.run/docs/mcp for details.
